What is the Flames game?

Flames game is a name matching game. Flames game is a pencil paper game that was used in the 90s to check the relationship status of two people by name.

Is FLAMES a Real Compatibility Test?

No. FLAMES is a recreational name game and is not a scientifically validated compatibility test.
